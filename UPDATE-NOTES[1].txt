Deep Cortex Designs Website — Update
=====================================

This replaces the site currently in the repo with the latest version:
mobile-responsive fixes + SEO metadata added.

WHAT TO DO
----------
1. In your local clone of Deep-Cortex-Designs-Main, replace index.html
   with the index.html in this folder.
2. styles.css and script.js are no longer used — the new index.html is
   fully self-contained (all CSS inline, no JS required). You can delete
   those two files from the repo, or just leave them unreferenced.
3. deep-cortex-logo.png and deep-cortex-banner.png are also no longer
   referenced (the new page embeds its own images directly), so those
   can stay or go — your call.
4. Commit and push as usual.

WHAT CHANGED FROM THE OLD VERSION
----------------------------------
This is a different, newer design than what was in the repo (the old
"No Website? No Problem." version) — it's the current Deep Cortex
Designs site: "Websites for small businesses across Canada, built by
one person who actually answers the phone."

Recent fixes in this version:
- Mobile: fixed an oversized logo that broke the nav on phones, added
  a working hamburger menu (the old one just hid the nav links with no
  way to reach them on mobile), fixed layout bugs that caused sideways
  scrolling and broken buttons on narrow screens.
- SEO: added page title, meta description, Open Graph/Twitter tags,
  canonical URL, and JSON-LD structured data (all in the page <head>,
  ready for search engines and social previews).
- Removed the non-functional contact form (now a simple "email me"
  button), and pointed the "Get a Quote" and "Claim founding rate"
  buttons at hello@deepcortexdesigns.ca.

TWO THINGS TO DOUBLE-CHECK BEFORE THIS GOES LIVE
--------------------------------------------------
1. Canonical/Open Graph URLs are currently set to
   https://deepcortexdesigns.ca/ — confirm that's the domain you'll
   actually use for GitHub Pages (if you're not using a custom domain
   yet, the real URL will be something like
   https://deepcortexdesigns.github.io/Deep-Cortex-Designs-Main/, and
   the meta tags in <head> should be updated to match). There's no
   CNAME file in this repo yet, so custom-domain routing isn't set up.
2. The structured data lists "Tina Desrochers" as founder, based on
   your email address — confirm that's correct/what you want public.
